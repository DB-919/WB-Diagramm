V1.3 ist eine echte Ein-Datei-Web-App. Zum Start wird nur index.html benötigt.

mehr verhindern, dass eine Datei geladen wird.

- 208-1-LG-10262314.TXT: 6.656 Punkte, CH1–CH4

Start:
index.html doppelklicken und TXT auswählen.

Falls eine Datei nicht lesbar ist, zeigt V1.3 nun direkt in der App eine
konkrete Fehlermeldung an.
